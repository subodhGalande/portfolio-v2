# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Primary audience: Full-time tech recruiters and hiring managers evaluating Subodh Galande for full-stack software engineering roles. They need a fast, scannable, and convincing breakdown of technical capabilities, real projects, and professional background.

## Product Purpose
To showcase Subodh Galande's full-stack development expertise, present proof of work through live project demonstrations and code repositories, and enable recruiters to quickly evaluate qualifications, review his resume, and get in touch.

## Positioning
A high-craft personal engineering portfolio of a Full-Stack Developer blending clean architecture, responsive interactive UI, and robust modern web technologies.

## Operating Context
Evaluated on desktop and mobile web browsers during candidate sourcing, resume screening, and interview loops. Visitors expect immediate access to working project demos, GitHub source code, professional socials, and a downloadable resume.

## Capabilities and Constraints
- **Capabilities**: Interactive Hero section, Tech Stack matrix, Featured Projects showcase, Work Experience timeline, direct contact channels, and resume download.
- **Technical Constraints**: Built with React 18, Vite, Tailwind CSS, Framer Motion, and Lenis smooth scrolling.

## Brand Commitments
- **Name**: Subodh Galande
- **Role**: Full-Stack Developer
- **Tone & Voice**: Professional, confident, technical, and creative.
- **Social / Contact Channels**: GitHub, LinkedIn, X (Twitter), Gmail, Resume (`/Subodh Galande.pdf`).

## Evidence on Hand
- Resume artifact located at `public/Subodh Galande.pdf`.
- Existing React component architecture (`Hero`, `Tech`, `Projects`, `experinces`, `Navbar`, `Footer`).

## Product Principles
1. **Scannability First**: Recruiters scan portfolios in seconds; present core role, skills, and project highlights upfront.
2. **Proof Over Claims**: Support full-stack claims with working project links, repository access, and high visual craft.
3. **Frictionless Reachability**: Make resume downloads and outreach via Gmail, LinkedIn, or GitHub a single-click action.
4. **Performance & Motion**: Ensure animations (Framer Motion / Lenis) feel smooth and responsive without degrading load speed or readability.
